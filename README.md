# Автоматизация перечня приложений

Проект VBA для настольного Excel под Windows для формирования и сопровождения перечня приложений к отчётам.

> **Текущий статус:** в репозитории появился первый исходный модуль VBA для формирования перечня. Он ещё не проверен на реальной рабочей книге и наборах документов; перед использованием необходимо протестировать его на копиях данных.

## Что уже есть в коде

Файл `src/vba/modApplicationsList.bas` содержит начальную реализацию макроса `CreateMultiFolderApplicationsListCorrected`:

- выбор нескольких исходных папок;
- рекурсивный поиск файлов Word, PDF и Excel с ограничением глубины;
- создание таблицы A:J с заголовком, гиперссылками и базовым форматированием;
- сортировка по объекту, приоритет основных отчётов и номера приложения;
- сохранение значений столбца H «Раздел» при перестроении листа по пути файла;
- попытка подстановки отдела и ответственного лица из листа `data`;
- обработка отмены и ошибок с восстановлением настроек Excel;
- статус выполнения в строке состояния и итоговое сообщение в Excel.

**Пока не реализовано в отдельных модулях:** поиск всех упоминаний приложений и определение страниц/уровней Word-отчёта, подсчёт страниц, безопасное переименование файлов с журналом и откатом, сбор листа `data_full`, автоматическая коррекция содержимого документов. Эти задачи остаются следующими этапами.

## Как импортировать модуль

1. Откройте копию рабочей книги Excel и сохраните её как книгу с поддержкой макросов (`.xlsm`).
2. Нажмите `Alt+F11`, чтобы открыть редактор VBA.
3. В редакторе выберите **File → Import File…** и укажите `src/vba/modApplicationsList.bas`, скачанный из репозитория.
4. Убедитесь, что в книге есть лист справочника с точным именем `data`. На нём столбец A содержит наименования, B — отделы, C1:F1 — заголовки объектов, C:F — ответственных лиц.
5. Запустите макрос `CreateMultiFolderApplicationsListCorrected` из Excel или редактора VBA.

Макрос рассчитан на настольный Excel под Windows. Для работы с Word-файлами дополнительных ссылок VBA не требуется, но Word должен быть установлен для будущих функций чтения страниц.

## Структура книги

- Лист перечня: строка 1 — объединённый заголовок «Перечень приложений», строка 2 — заголовки таблицы, данные начинаются со строки 3.
- Столбцы A:J: № п/п, Объект, № Прил., Наименование, Отдел, Ответственное лицо, Ссылка на файл, Раздел, Стр. отчёта, Кол-во страниц.
- Лист `data`: A — наименование приложения/отчёта, B — отдел, C:F — ответственные лица по объектам; названия объектов находятся в C1:F1.
- Столбец H «Раздел» заполняется вручную и должен сохраняться при перестроении перечня.

## Важные ограничения текущего модуля

- Правила извлечения объекта и наименования зависят от структуры папок и формата имени файла. Проверьте их на реальных примерах перед массовым запуском.
- Подсчёт страниц и заполнение столбцов «Стр. отчёта» и «Кол-во страниц» пока не реализованы.
- Переименование файлов и изменение содержимого документов не выполняются этим модулем.
- Проверьте формулы листа `data` и соответствие значений в столбце «Наименование» данным справочника.
- Запускайте макрос сначала на копиях папок и документов. Не считайте код протестированным, пока не пройдены сценарии из `tests/test-checklist.md`.
