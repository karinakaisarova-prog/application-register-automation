# Автоматизация перечня приложений

Проект VBA для Excel для формирования и сопровождения перечня приложений к отчётам по выбранным папкам.

> **Статус:** требования собраны; перед публикацией рабочего кода его нужно сверить с актуальной версией макросов и проверить на тестовой копии файлов.

## Планируемые возможности

- Выбор нескольких папок и сбор файлов приложений.
- Формирование таблицы с объектом, номером приложения, наименованием, отделом, ответственным лицом, ссылкой на файл, разделом, страницей отчёта и количеством страниц.
- Поиск файлов основного отчёта Word и подсчёт страниц.
- Сохранение вручную заполненного столбца «Раздел» при повторном формировании списка.
- Подстановка отдела и ответственного лица с листа-справочника `data`.
- Отдельные процедуры для поиска упоминаний приложений в отчёте и для переименования файлов.
- Подтверждение перед внесением изменений и возможность отменить выполнение макроса.
- Отображение статуса выполнения в Excel без отдельного файла журнала.

## Структура книги Excel

- Лист перечня: строка 1 — заголовок «Перечень приложений», строка 2 — заголовки таблицы, данные начинаются со строки 3.
- Лист `data`: столбец A — наименование приложения/отчёта, B — отдел, C:F — ответственные лица по объектам; названия объектов находятся в C1:F1.
- Столбец H «Раздел» заполняется вручную и должен сохраняться при перестроении перечня.

## Требования к безопасности изменений

1. Сначала сформировать отчёт и показать результаты проверки.
2. Перед исправлением документов запросить отдельное подтверждение.
3. Не переименовывать и не изменять исходные документы без явного подтверждения.
4. Перед массовыми операциями проверять совпадения имён и предусматривать отмену.
5. Проверять макросы на копиях файлов до использования в рабочей папке.

## Совместимость

Макросы предназначены для настольного Microsoft Excel под Windows. Для чтения и подсчёта страниц Word потребуется установленный Microsoft Word. Совместимость с конкретными версиями Office и форматы PDF необходимо проверить на целевой системе.
