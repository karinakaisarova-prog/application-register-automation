# Обработчик выгрузки 1С

## Назначение

Модуль `src/vba/mod1CReportFormatter.bas` содержит две процедуры:

- `StartForColleague` — открывает окно выбора файла выгрузки 1С и запускает обработку первого листа выбранной книги.
- `Format1CReportExact` — преобразует выгрузку: переносит реквизиты в столбец А, удаляет пустые столбцы внутри таблицы, находит столбцы даты и количества, добавляет промежуточные итоги и формулы, применяет числовой формат, шрифт, фильтр и ширину столбцов.

## Текущий статус

Это исходная версия для дальнейшей доработки. Логика пока не согласована окончательно и не считается проверенной на всех вариантах выгрузок 1С.

## Подключение в отдельной книге

1. Создать новую книгу Excel.
2. Сохранить её в формате `.xlsm`.
3. Открыть редактор VBA сочетанием Alt + F11.
4. Выбрать Insert → Module.
5. Импортировать файл `mod1CReportFormatter.bas` либо скопировать его код в стандартный модуль.
6. Создать на листе фигуру-кнопку и назначить ей макрос `StartForColleague`.

## Важные замечания перед передачей сотруднику

- Макрос открывает выбранную выгрузку и изменяет её содержимое. Перед запуском рекомендуется работать с копией исходного файла.
- В текущей версии нет автоматического сохранения результата под новым именем.
- В текущей версии сообщение об успешной обработке выводится и после некоторых штатных остановок по проверкам. Это необходимо исправить до передачи в постоянную эксплуатацию.
- При возникновении необработанной ошибки параметры Excel могут не восстановиться. Требуется добавить единый обработчик ошибок и гарантированное восстановление настроек.
- Вариант распространения через надстройку `.xlam` пока не реализован и будет рассматриваться отдельно.

## План дальнейшей доработки

Изменения вносить отдельными этапами, сохраняя исходную версию. Перед каждым изменением проверять актуальный файл и его SHA в GitHub.
