# Обработчик выгрузки 1С

## Файлы проекта

- VBA-модуль: [mod1CReportFormatter.bas](../src/vba/mod1CReportFormatter.bas).
- Исходный код для просмотра: [открыть на GitHub](https://github.com/karinakaisarova-prog/application-register-automation/blob/main/src/vba/mod1CReportFormatter.bas).
- Скачать модуль: [скачать файл .bas](https://raw.githubusercontent.com/karinakaisarova-prog/application-register-automation/main/src/vba/mod1CReportFormatter.bas).

## Назначение

Модуль содержит две процедуры:

- `StartForColleague` — открывает окно выбора файла выгрузки 1С, открывает выбранную книгу и запускает обработку её первого листа.
- `Format1CReportExact` — переносит реквизиты выгрузки в столбец A, удаляет пустые ячейки столбцов внутри области таблицы, ищет столбцы даты и количества, добавляет промежуточные итоги и формулы, применяет числовые форматы, шрифт, фильтр и ширину столбцов.

## Рекомендуемый способ использования

Для передачи сотруднику предусмотрен простой вариант: отдельная книга Excel с поддержкой макросов (`.xlsm`) и кнопкой запуска. Надстройка `.xlam` и горячая клавиша в текущий вариант не входят.

## Часть 1. Создание книги обработчика

1. Открой настольный Excel для Windows.
2. Создай новую пустую книгу.
3. Выбери **Файл → Сохранить как**.
4. В типе файла выбери **Книга Excel с поддержкой макросов (*.xlsm)**.
5. Сохрани книгу под именем, например, `Обработчик_1С.xlsm`.

## Часть 2. Импорт VBA-модуля

1. Открой страницу [mod1CReportFormatter.bas](https://github.com/karinakaisarova-prog/application-register-automation/blob/main/src/vba/mod1CReportFormatter.bas).
2. Скачай файл `.bas` по ссылке [Скачать модуль](https://raw.githubusercontent.com/karinakaisarova-prog/application-register-automation/main/src/vba/mod1CReportFormatter.bas).
3. В Excel нажми **Alt+F11**.
4. В редакторе VBA выбери **File → Import File…** (в русской версии — соответствующий пункт меню **Файл**).
5. Выбери скачанный `mod1CReportFormatter.bas`. Не вставляй строку `Attribute VB_Name` вручную в окно кода.
6. Убедись, что в проекте появился модуль `mod1CReportFormatter`.
7. Нажми **Ctrl+S** и закрой редактор VBA.

## Часть 3. Создание кнопки

1. На листе книги обработчика выбери **Вставка → Фигуры**.
2. Нарисуй прямоугольник.
3. Введи текст кнопки: **Обработать выгрузку 1С**.
4. Нажми на фигуру правой кнопкой мыши и выбери **Назначить макрос**.
5. Выбери `StartForColleague` и нажми **ОК**.
6. Сохрани книгу сочетанием **Ctrl+S**.

Если команда `StartForColleague` не появилась в списке, проверь, что модуль импортирован в эту книгу и что книга сохранена в формате `.xlsm`.

## Часть 4. Запуск

1. Открой книгу `Обработчик_1С.xlsm`.
2. Если Excel показывает предупреждение безопасности, разрешай макросы только если файл получен из доверенного источника и ты проверила его содержимое.
3. Нажми кнопку **Обработать выгрузку 1С**.
4. В окне выбора укажи файл выгрузки 1С.
5. Макрос откроет выбранный файл и обработает его первый лист.

## Важные ограничения текущей версии

- **Проверяй только на копии выгрузки.** Макрос изменяет открытую книгу с исходными данными.
- Макрос не сохраняет обработанный файл автоматически и не предлагает отдельное имя для результата. После проверки результата сохрани его вручную через **Файл → Сохранить как**.
- В текущем коде нет полноценного обработчика ошибок, который гарантированно возвращает настройки Excel при аварийном завершении.
- Сообщение об успешной обработке может появиться и после некоторых остановок по проверкам. Поэтому само сообщение не подтверждает, что все операции выполнены.
- Процедура использует первый лист выбранной книги. Перед запуском убедись, что нужная таблица находится именно на первом листе.
- Код пока не прошёл компиляцию и практическое тестирование на разных вариантах выгрузок 1С. Не используй его на единственном экземпляре рабочего файла.

## Что пока не делать

- Не устанавливай этот макрос как надстройку `.xlam`.
- Не настраивай горячую клавишу.
- Не передавай книгу сотрудникам как проверенный рабочий инструмент до завершения тестирования и исправления известных ограничений.
