# Оставшиеся работы и проверка готовности

## Статус на 2026-10-23

Код модулей VBA и документация находятся в репозитории. Наличие исходников не означает, что проект прошёл компиляцию и выполнение в Excel/Word.

## Обязательные проверки перед рабочим использованием

- [ ] Импортировать все модули из `src/vba` в тестовую книгу Excel с поддержкой макросов.
- [ ] Выполнить Debug → Compile VBAProject и устранить все ошибки компиляции.
- [ ] Проверить первый запуск `StartRegisterAutomation`: создание книги результата, копирование листа `data`, выбор нескольких папок, отмена выбора и очистка после ошибки.
- [ ] Проверить повторное построение перечня и сохранение вручную заполненных значений «Раздел» по пути файла.
- [ ] Проверить распознавание объекта по цепочке папок, включая вложенные папки и сетевые пути.
- [ ] Проверить поиск упоминаний приложений и номер страницы в реальных копиях Word-отчётов.
- [ ] Проверить подсчёт страниц Word/PDF/Excel на компьютере, где будут запускаться макросы; для PDF текущая инструкция предусматривает совместимый Adobe Acrobat Pro/Standard.
- [ ] Проверить переименование файлов, конфликты имён, недоступные файлы, Ctrl+Break и откат пакета на копиях данных.
- [ ] Проверить нумерацию таблиц и преобразование маркированных списков в Word на копиях отчётов, включая вложенные таблицы и подписи на границах страниц.
- [ ] Проверить панель управления и каждый назначенный кнопкам макрос.

## Функции, которые нельзя считать реализованными полностью

- **Переименование внутри содержимого файла** — отдельная операция пока не реализована; наличие кнопки для неё не подтверждено.
- **Отдельное приложение вне Excel** — текущая реализация является VBA-решением и использует Excel как интерфейс.
- **Полная гарантия отката** — восстановление после ошибок является попыткой best-effort и должно проверяться на копиях; абсолютная транзакционная гарантия не подтверждена.

## Критерий готовности

Проект можно считать проверенным для рабочего применения только после успешной компиляции и прохождения ручных тестов в целевой версии Windows, Excel и Word. До этого запускать изменения следует только на копиях файлов.
