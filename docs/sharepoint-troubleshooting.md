# SharePoint: поиск файлов и диагностика

## Рекомендуемый способ

Если библиотека SharePoint синхронизирована с компьютером через OneDrive/SharePoint, в диалоге выбора папки выбирайте именно локальную синхронизированную папку из Проводника Windows. Обычно путь начинается с буквы диска или профиля пользователя, например `C:\Users\...\...`, а не с `http://` или `https://`.

Макрос перебирает файлы через Windows FileSystemObject. Он не скачивает файлы из SharePoint через веб-интерфейс и не выполняет самостоятельную авторизацию в SharePoint.

## Если в журнале указан HTTP-адрес

В актуальном `src/vba/modApplicationsList.bas` функция `NormalizeSelectedRootPath` преобразует HTTP/HTTPS-адрес в UNC-путь Windows WebDAV. После преобразования в журнале должна появиться строка:

`Адрес SharePoint преобразован в путь Windows WebDAV: \\\\...`

Если журнал вместо этого продолжает сообщать об ошибке для исходного `http://...`, вероятно, запущена старая копия книги с предыдущей версией VBA. Установщик создаёт отдельную рабочую копию книги; изменения исходников в GitHub не обновляют уже установленную книгу автоматически.

## Если преобразованный WebDAV-путь недоступен

Преобразование URL в UNC само по себе не подтверждает доступность библиотеки. WebDAV-путь может не открываться из-за настроек службы WebClient, авторизации, прав доступа или конфигурации сервера. В таком случае используйте локальную синхронизированную папку и проверьте, что она открывается в Проводнике Windows под той же учётной записью.

## Что проверяет автоматическая проверка проекта

GitHub Actions проверяет структуру VBA, обязательные процедуры и некоторые защитные условия. Эта проверка не подключается к корпоративному SharePoint и не доказывает, что конкретная библиотека доступна с рабочего компьютера.
