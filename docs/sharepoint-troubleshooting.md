# SharePoint: поиск файлов и диагностика

## Выбор исходной папки

При запуске макрос предлагает два способа:

- **Да** — выбрать одну или несколько папок через Проводник Windows. Для SharePoint, синхронизированного через OneDrive, выбирайте именно локальную папку. Обычно путь начинается с буквы диска или профиля пользователя.
- **Нет** — вставить полный веб-адрес папки SharePoint, начинающийся с `http://` или `https://`. Макрос преобразует его в путь Windows WebDAV.

Макрос перебирает файлы через Windows FileSystemObject. Он не скачивает файлы через веб-интерфейс и не выполняет самостоятельную авторизацию в SharePoint. Преобразование ссылки в WebDAV-путь не гарантирует, что сервер доступен: должны быть настроены WebClient, авторизация и права доступа. Для синхронизированной папки используется обычный локальный путь Windows; он не преобразуется в WebDAV.

Процентное кодирование пути, в том числе кириллица и пробелы в формате UTF-8, декодируется перед преобразованием в WebDAV-путь. Вставляйте прямой адрес папки, а не ссылку общего доступа, в которой сам путь может быть скрыт в параметрах запроса. Параметры после `?` и фрагмент после `#` при преобразовании отбрасываются.

## Пример преобразования адреса

Для адреса `http://stksps01:55555/SD/Совместное редактирование/НТУ/Отчет НТУ за 3 квартал 2026/НТУ приложения` текущая функция формирует путь `\\stksps01@55555\DavWWWRoot\SD\Совместное редактирование\НТУ\Отчет НТУ за 3 квартал 2026\НТУ приложения`.

Это ожидаемый результат разбора адреса, а не подтверждение существования сетевого ресурса. Если Windows не открывает сформированный путь в Проводнике под той же учётной записью, макрос также не сможет перечислить файлы через `FileSystemObject`. В таком случае выберите синхронизированную папку через диалог Windows.

## Если в журнале указан HTTP-адрес

В актуальном `src/vba/modApplicationsList.bas` функция `NormalizeSelectedRootPath` преобразует HTTP/HTTPS-адрес в UNC-путь Windows WebDAV. После преобразования в журнале должна появиться строка:

`Адрес SharePoint преобразован в путь Windows WebDAV: \\\\...`

Если журнал вместо этого продолжает сообщать об ошибке для исходного `http://...`, вероятно, запущена старая копия книги с предыдущей версией VBA. Установщик создаёт отдельную рабочую копию книги; изменения исходников в GitHub не обновляют уже установленную книгу автоматически.

## Если преобразованный WebDAV-путь недоступен

Преобразование URL в UNC само по себе не подтверждает доступность библиотеки. Не вставляйте в поле веб-адреса ссылку общего доступа или ссылку на страницу просмотра файла, если в ней реальный путь к папке скрыт в параметрах запроса. WebDAV-путь может не открываться из-за настроек службы WebClient, авторизации, прав доступа или конфигурации сервера. В таком случае используйте локальную синхронизированную папку и проверьте, что она открывается в Проводнике Windows под той же учётной записью.

## Что проверяет автоматическая проверка проекта

GitHub Actions проверяет структуру VBA, обязательные процедуры и некоторые защитные условия. Эта проверка не подключается к корпоративному SharePoint и не доказывает, что конкретная библиотека доступна с рабочего компьютера.
