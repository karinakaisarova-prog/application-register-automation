# Инструкция для пользователя без опыта работы с макросами

Эта инструкция рассчитана на человека, который не пишет код и хочет пользоваться готовым инструментом.

## Важно: что готово, а что пока нет

Исходный код хранится в GitHub, но это ещё не готовая программа, которую можно просто скачать и запустить. Модули пока не прошли полную компиляцию и проверку в настоящем Excel и Word.

**Не нужно заранее создавать пустую книгу Excel.** Целевой сценарий проекта — запускать макрос из отдельного файла-запускателя, после чего он сам создаёт новую книгу с перечнем. Архитектура такого запуска и связь кнопок с созданной книгой ещё дорабатываются. До завершения этой работы нельзя считать инструкции по обычному запуску готовыми.

## Как будет выглядеть обычная работа

Пока отдельный готовый файл для запуска ещё не собран и код не прошёл проверку в Excel. Поэтому описанный ниже сценарий — порядок для первой тестовой сборки, а не подтверждение готовности программы. Для первоначальной настройки потребуется один раз импортировать модули из репозитория в книгу с макросами и сохранить её в формате `.xlsm`.

1. Открыть книгу с макросами в формате `.xlsm`. В ней должны быть импортированы все `.bas`-модули из папки `src/vba`, включая `modWorkbookContext.bas`. Это разовая техническая настройка; отдельный готовый установочный файл пока не подготовлен.
2. Если Excel покажет предупреждение о макросах, разрешать их запуск только для файла, полученного из доверенного источника проекта. Не включать макросы в случайных файлах из интернета.
3. Нажать `Alt+F8`, выбрать `StartRegisterAutomation` и нажать «Выполнить». Этот макрос должен создать отдельную книгу результата и затем показать окно выбора папок. Если такого имени нет в списке, остановиться: модуль запуска не импортирован.
4. В появившемся окне выбрать одну или несколько папок с отчётами и приложениями. Книгу с макросами-запускателем не закрывать: кнопки в книге результата вызывают код из неё.
5. Дождаться сообщения об окончании. Во время обработки можно прервать макрос клавишами Ctrl+Break; после прерывания нужно прочитать сообщение и проверить результат.
6. Проверить сформированный перечень: объект, номер приложения, наименование, отдел, ответственное лицо и ссылки на файлы.
7. При необходимости заполнить вручную столбец «Раздел». Не запускать переименование, пока не проверены все новые имена.
8. Другие кнопки использовать только по необходимости:
   - анализ упоминаний — для поиска упоминаний приложений в основном Word-отчёте;
   - подсчёт страниц — для отдельного заполнения количества страниц;
   - data_full — после заполнения разделов и ответственных лиц;
   - переименование — только после проверки предварительного списка и подтверждения;
   - откат переименования — для отмены последнего пакета, если журнал и файлы остались на месте;
   - проверка таблиц и маркированных списков — для проверки Word-документа. Перед исправлением сохранять отдельную копию документа.
9. Сохранить итоговую книгу в выбранное место через «Файл → Сохранить как» и выбрать формат книги Excel (`.xlsx` подходит для результата без макросов; сам код остаётся в книге-запускателе `.xlsm`). Не удалять резервные копии, журнал переименования или исходные документы, пока результат не проверен.

## Правила безопасности

- Первые запуски проводить только на копиях папок и документов.
- Не подтверждать переименование, если хотя бы одно имя выглядит неверно.
- Не закрывать Excel принудительно во время обработки, если можно штатно прервать макрос.
- Если появляется ошибка, сохранить текст сообщения и не повторять операцию вслепую.
- Если после ошибки появилась резервная или восстановительная копия листа, не удалять её до проверки данных.
- Не считать наличие кнопки доказательством того, что операция уже протестирована.

## Если что-то пошло не так

1. Записать полный текст сообщения об ошибке.
2. Проверить, остались ли исходные файлы на месте и не изменились ли их имена.
3. Не запускать повторно переименование или исправление Word, пока не выяснена причина.
4. Передать сообщение об ошибке вместе с названием кнопки, которую нажали, и описанием последнего действия.

После проверки кода инструкцию нужно упростить до запуска готового файла двойным щелчком. Сейчас отдельный установочный файл не создан, а код и кнопки не проверены в работающем Excel/Word.
