# Чек-лист перехода к автоматически создаваемой книге перечня

Этот документ фиксирует условия, которые нужно выполнить до объявления проекта готовым для обычного пользователя.

## Обязательные изменения

- [x] Установщик создаёт отдельную `.xlsm`-копию исходной книги и импортирует VBA-модули в неё; исходный файл не перезаписывается.
- [x] При запуске лист перечня создаётся в той же рабочей книге, где уже находится справочник `data`; имя листа берётся из выбранной папки.
- [x] Лист `data` остаётся в копии исходной книги; если его нет в рабочей книге, запуск завершается с понятным сообщением.
- [ ] Если перечень перестраивается из существующей книги результата, значения столбца H «Раздел» переносятся по нормализованному пути файла.
- [ ] Все макросы, запускаемые кнопками на листе результата, находят именно эту книгу, а не книгу-запускатель.
- [ ] Журнал переименования и лист `data_full` создаются в книге результата.
- [ ] Проверить в Excel, что кнопки панели работают в той же книге, где создан перечень.
- [ ] Инструкция для начинающих описывает только проверенный способ запуска и отдельно объясняет сохранение результата.

## Проверки перед выпуском

- [ ] Импортировать все модули в тестовую книгу Excel для Windows.
- [ ] Выполнить `Debug → Compile VBAProject` и устранить все ошибки компиляции и дублирующиеся имена процедур.
- [ ] Запустить создание перечня на тестовых папках с несколькими вложенными уровнями и поддерживаемыми форматами.
- [ ] Убедиться, что перечень создаётся в той же книге, что и `data`, без открытия отдельной книги результата.
- [ ] Проверить кнопки анализа отчёта, подсчёта страниц, `data_full`, переименования и отката именно в книге результата.
- [ ] Проверить отмену через Ctrl+Break и поведение при ошибке доступа к папке/файлу.
- [ ] Проверить переименование и откат на копиях файлов; убедиться, что журнал находится в книге результата.
- [ ] Проверить Word-макросы на копиях документов, включая подписи таблиц SEQ и маркированные списки.
- [ ] Обновить `docs/instruction-for-beginners.md` по фактически проверенному поведению.

## Текущий статус

Этот чек-лист — план работ, а не подтверждение выполнения пунктов. VBA-код проекта пока не скомпилирован и не проверен в работающем Excel/Word. До завершения проверок проект нельзя считать готовым к повседневному использованию.
