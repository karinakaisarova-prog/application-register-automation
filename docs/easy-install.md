# Установка книги Excel без ручного импорта модулей

Установщик Windows `tools/Установить_книгу_Excel.cmd` добавляет VBA-модули в **копию твоей существующей Excel-книги**, где уже есть лист `data`. Все листы выбранной книги сохраняются; отдельная книга результата для перечня не создаётся.

## Требования

- Windows и установленный настольный Microsoft Excel.
- Полностью распакованный ZIP-архив репозитория: установщик должен видеть папку `src/vba`.
- В исходной книге должен быть лист с точным именем `data`.
- Разрешённый Excel доступ к объектной модели проектов VBA. Если доступ заблокирован, установщик покажет инструкцию. Не включайте эту настройку без понимания последствий: разрешение позволяет программно менять VBA-проекты.

## Как пользоваться

1. На странице репозитория нажмите **Code → Download ZIP**, затем распакуйте весь архив в папку.
2. Откройте распакованную папку и зайдите в `tools`.
3. Дважды нажмите `Установить_книгу_Excel.cmd`.
4. В первом диалоге выберите свою существующую Excel-книгу, в которой уже находится лист `data`.
5. Во втором диалоге укажите имя и место для новой копии с макросами. Исходная книга не перезаписывается.
6. Если установщик сообщит, что Excel блокирует доступ к VBA-проекту, следуйте подсказке только если готовы разрешить такой доступ. Затем закройте Excel и повторите запуск.
7. Откройте созданную копию `.xlsm` в настольном Excel, нажмите **Alt+F11 → Debug → Compile VBAProject**.
8. Если компиляция выдаст ошибку, остановитесь и сохраните текст ошибки/скриншот. Не запускайте макросы и не меняйте оригинальные документы.
9. После успешной компиляции запустите `StartRegisterAutomation`. Он проверит лист `data` и предложит выбрать исходные папки; перечень будет создан в этой же книге.

## Важно

- Копия сохраняет лист `data` и другие листы исходной книги. Перечень и вспомогательные листы появятся в созданной копии, а не в исходном файле.
- Установщик автоматизирует импорт, но не доказывает, что VBA скомпилируется или правильно выполнится в конкретной версии Excel. Он не заменяет проверку в Excel.
- Установщик не изменяет исходный файл. Сохраняйте рабочие изменения уже в новой `.xlsm`-копии после проверки.
- Это установщик для Windows и настольного Excel, не для Excel Online или macOS.
- В репозитории нет готовой подписанной/предварительно скомпилированной `.xlsm`-книги; копия создаётся на компьютере пользователя.
