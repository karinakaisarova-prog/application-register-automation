# Установка книги Excel без ручного импорта модулей

Для пользователя подготовлен установщик Windows: \`tools/Установить_книгу_Excel.cmd\`. Он собирает девять VBA-модулей из \`src/vba\` в новую книгу \`.xlsm\` и предлагает выбрать место сохранения.

## Требования

- Windows и установленный настольный Microsoft Excel.
- Полностью распакованный ZIP-архив репозитория: установщик должен видеть папку \`src/vba\`.
- Разрешённый Excel доступ к объектной модели проектов VBA. Если доступ заблокирован, установщик покажет инструкцию. Не включайте его без понимания последствий: разрешение позволяет программно менять VBA-проекты.

## Как пользоваться

1. На странице репозитория нажмите **Code → Download ZIP**, затем распакуйте весь архив в папку.
2. Откройте распакованную папку и зайдите в \`tools\`.
3. Дважды нажмите \`Установить_книгу_Excel.cmd\`.
4. В диалоге выберите место и имя создаваемой книги \`.xlsm\`.
5. Если установщик сообщит, что Excel блокирует доступ к VBA-проекту, следуйте подсказке только если готовы разрешить такой доступ. Затем закройте Excel и повторите запуск.
6. После создания откройте новую \`.xlsm\`-книгу в настольном Excel, нажмите **Alt+F11 → Debug → Compile VBAProject**.
7. Если компиляция выдаст ошибку, остановитесь и сохраните текст ошибки/скриншот. Не запускайте макросы и не меняйте оригинальные документы.
8. Если компиляция успешна, подготовьте лист \`data\` с реальными данными согласно [README](../README.md) и переходите к тесту на копиях файлов.

## Важно

- Установщик автоматизирует импорт, но не доказывает, что VBA скомпилируется или правильно выполнится в конкретной версии Excel. Он не заменяет проверку в Excel.
- Установщик создаёт новую книгу и не меняет существующие книги.
- Если в выбранной папке уже есть файл с таким именем, диалог спросит подтверждение перезаписи.
- Это установщик для Windows и настольного Excel, не для Excel Online или macOS.
- В репозитории пока нет готовой подписанной/предварительно скомпилированной \`.xlsm\`-книги; она создаётся на компьютере пользователя.
