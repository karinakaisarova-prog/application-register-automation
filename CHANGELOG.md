# История изменений

## 2026-10-21

- Добавлен начальный модуль формирования перечня `src/vba/modApplicationsList.bas`.
- Добавлен модуль анализа Word-отчёта и подсчёта страниц `src/vba/modReportAnalysis.bas`.
- Добавлен модуль переименования файлов с предварительным подтверждением, журналом и процедурой отката `src/vba/modRenameFiles.bas`.
- Добавлен модуль построения уникальных пар «Раздел — Ответственное лицо» на листе `data_full`.
- Обновлены README и ручной чек-лист тестирования.
- Исправлена регулярная выражение поиска упоминаний: заменена потенциально несовместимая группа `(?:...)`.
- Исправлена обработка Ctrl+Break при обходе папок: отмена должна передаваться главному обработчику, а не подавляться обработчиком ошибки папки.
- Улучшен разбор имён файлов: поддерживается вариант «Приложение номер 15»; скорректирован индекс подгруппы номера после расширения регулярного выражения.
- Безопаснее организован откат переименования: добавлен ID пакета, чтобы откатывать только последний запуск, а не все оставшиеся в журнале операции.
- Исправлен выбор пакета отката: после полного отката последнего пакета следующий запуск может выбрать предыдущий пакет с ещё не отменёнными успешными переименованиями.
- ID пакета теперь включает номер следующей строки журнала, чтобы различать запуски, начавшиеся в одну секунду.
- При выборе пересекающихся папок добавлено отслеживание полных путей, чтобы один файл не попадал в перечень повторно.
- В распознавании основных отчётов учтены варианты префикса «Отчет/Отчёт» с пробелом или подчёркиванием.
- Исправлено определение объекта: используются только `СМТ`, `АМТ`, `КТ`, `КЗТ`, `Саратов`, `НТУ`; сначала проверяются названия папок от вложенной к родительской, затем имя файла. Если объект не найден, значение не подставляется.
- Поиск объекта расширен на весь путь к папке, включая родительские папки выше выбранной: выбор одной подпапки внутри папки объекта больше не мешает определить объект по имени родителя.
- Исправлено сопоставление путей при сохранении ручного столбца «Раздел»: нормализуются разделители, адреса `file:///...` и `%20` в пробелах.
- Уточнено распознавание специальных файлов для столбца «Отдел»: тире ставится только для точных базовых имён «Отчет_2 кв 2026» и «Реестр рисков», а не для любого названия с фразой «2 кв 2026».
- Статус: изменения записаны в репозиторий, но компиляция и практическое тестирование в целевой версии Excel/Word ещё не выполнены.
