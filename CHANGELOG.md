# История изменений

## 2026-11-18 — проверка кода и исправления

Код проверен построчно (три независимых проверки по группам модулей), спорные места проверены на установленных Excel и Word. Компиляция в редакторе VBA по-прежнему не выполнялась.

**Ошибки, из-за которых макросы не работали совсем**

- `modReportAnalysis`: вызов несуществующей процедуры `LogRestoreIssue` — из-за неё не компилировался **весь проект**.
- `modTableNumbering`: `wdDoc.CaptionLabels` — у документа Word такого свойства нет (ошибка 438), нумерация таблиц падала при каждом запуске; теперь `wdApp.CaptionLabels`.
- `modTableNumbering`: формат номера `\# "'Таблица № '0'"` с непарным апострофом — Word писал в каждой подписи «Ошибка! Строка шаблона содержит непарные кавычки» (проверено в Word); теперь `\# "'Таблица № '0"`.
- `modTableNumbering`: `fld.Range` — у поля Word нет свойства `Range`; удаление текста перед полем переписано через `fld.Code.Start`.
- `tools/setup_excel.ps1`: модули импортировались в UTF-8, а редактор VBA читает только кодировку Windows — вся кириллица в коде превращалась в «кракозябры». Установщик перекодирует модули в Windows-1251 перед импортом; для ручного импорта добавлен `tools/prepare_import_files.ps1`.
- После сохранения книги Excel хранит ссылки относительно её папки (`sub/doc.pdf`, проверено в Excel): терялся столбец «Раздел» при перестроении, переименование и подсчёт страниц не находили файлы. Добавлена общая `ResolveLinkPath` в `modWorkbookContext`.

**Потеря или порча данных**

- `modDataFull`, `modReportAnalysis`: копия листа бралась через `ActiveSheet` — при скрытом листе им оказывался перечень, который затем переименовывался и удалялся. Теперь копия берётся по позиции.
- `modApplicationsList`: лист с именем папки, который не является перечнем, затирался. Теперь проверяются заголовки, перечень получает другое имя; при сбое удаляется только лист, созданный в этом запуске.
- `modTableNumbering`: поиск подписи над таблицей «перепрыгивал» через предыдущую таблицу — таблица без подписи считалась подписанной. Подписи «Таблица 2.3», «Табл. 7», подписи с полями не меняются и помечаются «ручная проверка» (раньше получали вторую подпись или портились).
- `modBulletListAudit`: ячейки таблиц объединялись в «список», маркеры попадали в чужие ячейки — теперь абзацы таблиц не участвуют.
- `modRenameFiles`: откат возвращал ссылку в строку по номеру из журнала — после пересборки перечня в чужую строку; теперь строка ищется по пути. Книга сохраняется после отката. `Dir$`/`Name` заменены на FileSystemObject (любые буквы в именах, без ошибки 52 на неверном пути). Переносы строк убираются из имени файла.
- `modReportAnalysis`: подсчёт страниц закрывал книгу Excel, уже открытую у пользователя.

**Зависания и прочее**

- Невидимый Word открывается без диалогов (`DisplayAlerts = 0`), без макросов документа, закрывается без вопроса о шаблоне Normal — Excel не «виснет» на невидимом окне. Документ, открытый у коллеги или защищённый, не меняется.
- На время правок Word выключается режим исправлений (иначе удалённый текст оставался исправлением).
- Окно подтверждения переименования не длиннее видимой части; полный план и пропуски — на листе «Пропуски переименования».
- Выбор нескольких папок по очереди (окно Windows позволяет выбрать только одну); «Отмена» в первом вопросе — выход; длинный адрес SharePoint не обрезается молча; временные файлы `~$…`, скрытые файлы и сама книга не попадают в перечень; вложенные папки глубже 3 уровней отмечаются в журнале.
- Формулы «Отдел»/«Ответственное лицо» записываются на английском (`.Formula`) — не зависят от разделителя списков Windows.
- Ячейка с ошибкой формулы (#Н/Д) в строках 1–2 любого листа больше не обрывает поиск перечня.
- `tools/validate_vba.py`: проверки обновлены под новый код; добавлены проверки вызова несуществующих процедур, непарных апострофов в формате номера таблицы и `wdDoc.CaptionLabels`.

## 2026-10-21

- Добавлен начальный модуль формирования перечня `src/vba/modApplicationsList.bas`.
- Добавлен модуль анализа Word-отчёта и подсчёта страниц `src/vba/modReportAnalysis.bas`.
- Добавлен модуль переименования файлов с предварительным подтверждением, журналом и процедурой отката `src/vba/modRenameFiles.bas`.
- Добавлен модуль построения уникальных пар «Раздел — Ответственное лицо» на листе `data_full`.
- Обновлены README и ручной чек-лист тестирования.
- Исправлена регулярная выражение поиска упоминаний: заменена потенциально несовместимая группа `(?:...)`.
- Исправлена обработка Ctrl+Break при обходе папок: отмена должна передаваться главному обработчику, а не подавляться обработчиком ошибки папки.
- Улучшен разбор имён файлов: поддерживается вариант «Приложение номер 15»; скорректирован индекс подгруппы номера после расширения регулярного выражения.
- Безопаснее организован откат переименования: добавлен ID пакета, чтобы откатывать только последний запуск, а не все оставшиеся в журнале операции.
- Исправлен выбор пакета отката: после полного отката последнего пакета следующий запуск может выбрать предыдущий пакет с ещё не отменёнными успешными переименованиями.
- ID пакета теперь включает номер следующей строки журнала, чтобы различать запуски, начавшиеся в одну секунду.
- При выборе пересекающихся папок добавлено отслеживание полных путей, чтобы один файл не попадал в перечень повторно.
- В распознавании основных отчётов учтены варианты префикса «Отчет/Отчёт» с пробелом или подчёркиванием.
- Исправлено определение объекта: используются только `СМТ`, `АМТ`, `КТ`, `КЗТ`, `Саратов`, `НТУ`; сначала проверяются названия папок от вложенной к родительской, затем имя файла. Если объект не найден, значение не подставляется.
- Поиск объекта расширен на весь путь к папке, включая родительские папки выше выбранной: выбор одной подпапки внутри папки объекта больше не мешает определить объект по имени родителя.
- Исправлено сопоставление путей при сохранении ручного столбца «Раздел»: нормализуются разделители, адреса `file:///...` и `%20` в пробелах.
- Уточнено распознавание специальных файлов для столбца «Отдел»: тире ставится только для точных базовых имён «Отчет_2 кв 2026» и «Реестр рисков», а не для любого названия с фразой «2 кв 2026».
- Статус: изменения записаны в репозиторий, но компиляция и практическое тестирование в целевой версии Excel/Word ещё не выполнены.
