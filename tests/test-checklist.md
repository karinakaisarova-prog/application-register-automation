# Чек-лист ручного тестирования

Проводить тесты только на копиях файлов. Отмечать результат и версию Office/Windows.

## Подготовка
- [ ] Создана тестовая папка с несколькими объектами и вложенными папками.
- [ ] Есть Word-отчёт, Word-приложение, PDF-приложение и Excel-приложение.
- [ ] Есть файл, название которого не соответствует шаблону, и файл с кириллицей/пробелами в имени.
- [ ] На листе `data` заполнены тестовые названия приложений, отделы, объекты и ответственные лица.
- [ ] В существующем перечне вручную заполнено несколько значений в столбце H «Раздел».

## Формирование перечня
- [ ] Можно выбрать одну папку.
- [ ] Можно выбрать несколько папок.
- [ ] Если одновременно выбраны родительская папка и вложенная в неё папка, каждый файл попадает в перечень только один раз.
- [ ] Отмена диалога выбора папок завершает операцию без повреждения книги.
- [ ] Объект определяется только из шести значений: `СМТ`, `АМТ`, `КТ`, `КЗТ`, `Саратов`, `НТУ`.
- [ ] При поиске объекта проверяются имена папок от вложенной к родительской по всему пути, включая родительские папки выше выбранной, затем имя файла.
- [ ] Если выбрана только подпапка внутри папки объекта, объект определяется по имени родительской папки.
- [ ] Совпадение с кодом объекта внутри другого слова не считается.
- [ ] Если объект не найден ни в папках, ни в имени файла, столбец «Объект» остаётся пустым.
- [ ] В столбце «Объект» отражается найденный объект, а не произвольное имя выбранной папки.
- [ ] Соблюдается ограничение глубины обхода папок.
- [ ] Отчёты распознаются по согласованному правилу.
- [ ] Основные отчёты распознаются с префиксами «Отчет_», «Отчёт_», «Отчет » и «Отчёт »; префикс не попадает в поле «Наименование».
- [ ] Номера приложений и наименования корректно извлекаются из тестовых имён.
- [ ] Проверены имена `СМТ_Приложение № 1_Земельные участки.pdf`, `АМТ_Приложение номер 15_Фототчет.pdf` и имя без номера приложения.
- [ ] В номере с буквенным суффиксом (например, `15А`) буква не теряется.
- [ ] Файлы группируются и сортируются в ожидаемом порядке.
- [ ] Ссылки открывают правильные файлы.
- [ ] Переименование корректно читает пути гиперссылок в формате `file:///...`, с `%20` вместо пробелов и с прямыми слешами.
- [ ] Подсчёт страниц корректно читает пути гиперссылок в формате `file:///...`, с `%20` вместо пробелов и с прямыми слешами.
- [ ] Форматирование соответствует требованиям; FreezePanes не используются.
- [ ] Значения «Раздел» сохраняются при повторном построении по пути файла.
- [ ] Сохранение «Раздела» работает, если гиперссылка хранит путь как `file:///...` или использует `%20` для пробелов.
- [ ] Файл с названием, содержащим фразу «2 кв 2026» как часть более длинного названия, не получает тире автоматически в столбце «Отдел».
- [ ] Отдел и ответственное лицо подставляются из листа `data`.
- [ ] Только для файлов с точными базовыми именами «Отчет_2 кв 2026» и «Реестр рисков» в отделе отображается «—».
- [ ] Недоступный/повреждённый файл не прекращает всю обработку без понятного сообщения.

## Word: страницы и упоминания
- [ ] Подсчёт страниц проверен на документе с несколькими страницами.
- [ ] Поиск находит несколько упоминаний одного приложения.
- [ ] Найденные страницы соответствуют расположению упоминаний в Word.
- [ ] Уровень структуры соответствует уровню абзаца Word для документов с несколькими уровнями заголовков.
- [ ] PDF-страницы подсчитываются только при наличии совместимого Adobe Acrobat Pro/Standard; без него появляется понятное сообщение.
- [ ] Таблицы и абзацы внутри таблиц Word проверены отдельно, так как структура отчёта может влиять на полноту поиска.
- [ ] Отсутствие совпадений обрабатывается без ошибки.

## Word: подписи и нумерация таблиц
- [ ] Предварительный отчёт на листе «Проверка таблиц» содержит все ожидаемые таблицы основного документа.
- [ ] Существующее поле `SEQ Таблица` распознаётся и не получает вторую подпись.
- [ ] Таблица без поля `SEQ Таблица` попадает в предварительный отчёт.
- [ ] Отказ от подтверждения не изменяет Word-документ.
- [ ] После подтверждения над таблицей добавляется подпись с автоматическим полем Word `SEQ`.
- [ ] После обновления полей номера таблиц идут последовательно, а ссылки/содержание обновлены там, где применимо.
- [ ] Проверены таблицы внутри ячеек, вложенные таблицы, подписи с пустыми строками и таблицы около разрывов страниц.
- [ ] Исходный документ до теста скопирован; изменения проверены визуально.

## Word: маркированные списки
- [ ] Группа из двух и более абзацев с ручными дефисами/тире попадает в лист «Проверка списков».
- [ ] Обычный текст с одиночным тире не преобразуется.
- [ ] Уже оформленный нативный список Word не меняется.
- [ ] Отказ от подтверждения оставляет документ без изменений.
- [ ] После подтверждения ручные маркеры удаляются, применяется настоящий маркированный список Word.
- [ ] Проверены группы в начале/конце страницы, разные отступы, табуляции, пустые строки и абзацы в таблицах.
- [ ] После преобразования визуально проверены уровни списка, переносы и отступы.
- [ ] При отмене посреди операции документ проверен на частично внесённые изменения.

## Переименование
- [ ] До изменения показывается список старых и новых имён.
- [ ] Отказ от подтверждения оставляет файлы без изменений.
- [ ] Расширение сохраняется.
- [ ] Недопустимые символы и пустые обязательные поля обрабатываются.
- [ ] Дубликаты целевых имён обнаруживаются до операции.
- [ ] Существующий файл с целевым именем не перезаписывается.
- [ ] Журнал содержит старый путь, новое имя, новый путь и статус каждой попытки.
- [ ] RollbackLastRenameBatch возвращает имена только последнего пакета на копиях файлов и обновляет гиперссылки в листе перечня.
- [ ] Повторный откат не затрагивает предыдущие пакеты переименования.
- [ ] После полного отката последнего пакета повторный запуск отката выбирает предыдущий пакет, если в нём ещё остались переименованные файлы.
- [ ] Два запуска в одну секунду получают разные ID пакетов.
- [ ] Старый журнал без ID пакета не запускает автоматический массовый откат.
- [ ] Откат пропускает файлы, если исходное имя уже занято.

## Вспомогательный лист data_full
- [ ] BuildDataFull собирает уникальные пары «Раздел» + «Ответственное лицо».
- [ ] Пустые разделы или ответственные лица не попадают в итоговый лист.
- [ ] Повторный запуск обновляет data_full без дублирования пар.
- [ ] Перед перестроением существующего data_full создаётся временная копия листа.
- [ ] При Ctrl+Break во время заполнения исходный data_full восстанавливается из копии.
- [ ] При искусственно вызванной ошибке во время перестроения исходный data_full восстанавливается.
- [ ] После успешного запуска временная копия удаляется и не остаётся лишних листов.
- [ ] Если листа data_full раньше не было, при отмене/ошибке не остаётся частичный новый лист.

## Отмена и восстановление
- [ ] Длительную операцию обхода папок можно прервать через Ctrl+Break; после отмены Excel восстанавливает настройки.
- [ ] Поиск упоминаний проверен на вариантах «Приложение № 12», «Приложения 12» и «Приложение номер 12».
- [ ] После отмены восстанавливаются настройки Excel.
- [ ] После ошибки восстанавливаются настройки Excel.
- [ ] Статус выполнения виден в Excel; отдельный лог-файл не создаётся.

## Общая проверка отмены и отката для КАЖДОГО макроса
Для каждого запускаемого макроса выполнить отдельный набор проверок:
- [ ] До начала изменений есть предварительный отчёт/подтверждение, если макрос меняет данные или документы.
- [ ] Отказ от подтверждения не меняет книгу, документы и файлы.
- [ ] На длительном этапе можно выполнить Ctrl+Break; макрос прекращает работу и не продолжает следующие изменения.
- [ ] После отмены восстанавливаются все изменённые настройки Excel и освобождаются объекты Word/файлов.
- [ ] При отмене/ошибке пользователь получает сообщение, какие изменения успели пройти и выполнен ли откат.
- [ ] До правок создана резервная копия или снимок исходного состояния.
- [ ] Процедура отката возвращает исходное состояние именно этого запуска и не затрагивает более ранние операции.
- [ ] Если откат невозможен полностью, каждый пропущенный элемент отмечается; ложное сообщение об успешном полном откате не показывается.
- [ ] После успешного запуска можно вызвать предусмотренный откат и проверить, что исходное состояние восстановлено.
- [ ] Повторный запуск, прерывание в середине и ошибка доступа проверены на копиях.

## Дополнительные тесты восстановления листа перечня

- [ ] При успешном перестроении существующего листа перечень обновлён, временный лист `_bak_register*` удалён.
- [ ] При Ctrl+Break во время сканирования/построения существующий лист восстановлен, исходные ручные значения в «Раздел» сохранены.
- [ ] При искусственной ошибке после начала построения не остаётся частично сформированного перечня вместо исходного.
- [ ] При первом создании листа и ошибке неполный новый лист удаляется.
- [ ] Проверить сценарии, когда структура книги защищена, и зафиксировать ожидаемое сообщение об ограничении восстановления.


## Проверка резервного копирования Word

- [ ] Для нумерации таблиц после подтверждения рядом с исходным файлом создаётся резервная копия с уникальным именем.
- [ ] Для преобразования маркировки после подтверждения рядом с исходным файлом создаётся резервная копия с уникальным именем.
- [ ] После успешной обработки путь к копии отображается пользователю, копия остаётся на диске.
- [ ] При Ctrl+Break во время редактирования документ закрывается без сохранения и исходный файл остаётся неизменным.
- [ ] При искусственной ошибке после сохранения исходный файл восстанавливается из копии.
- [ ] Если восстановление не удалось (например, нет прав доступа), сообщение и резервная копия позволяют выполнить ручное восстановление.
- [ ] Проверить длинные пути, кириллицу, файлы DOC/DOCX/DOCM и занятый/только для чтения файл.


## Проверка прерывания пакетного переименования

- [ ] Подготовить несколько тестовых файлов и прервать пакет после 1–2 успешных переименований.
- [ ] Проверить, что файлы по возможности возвращены к исходным именам, а гиперссылки перечня восстановлены.
- [ ] Проверить случай, когда исходное имя занято к моменту отката: файл не перезаписывается, проблема сообщается.
- [ ] Сверить журнал переименования с фактическими путями после автоматического отката.
- [ ] Проверить восстановление исходных настроек Excel после отмены и после обычного завершения.
